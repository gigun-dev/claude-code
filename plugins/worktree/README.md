# worktree — git-wt で git worktree を扱う

`git wt`(k1LoW/git-wt)と `git wtpr` による worktree 操作の skill。
`git-wt` / `git-wtpr` は PATH にあること(このリポジトリは導入しない)。

## 出典

[ryoppippi/dotfiles](https://github.com/ryoppippi/dotfiles)(MIT)の
`agents/skills/worktree` を原本のまま写している。上流 repo・path・固定 commit は
[`vendor/upstream-skills.json`](../../vendor/upstream-skills.json) が持ち、
週次の GitHub Actions が差分確認 PR を出す。手で編集しない。
