# harness を触るときに読むもの

**現在地・次の作業は `docs/harness/next-directions.md`(repo ルート相対)にある。
このディレクトリを編集する前に読むこと。** 作業の区切りごとに必ずそちらを更新する
(完了は打ち消し線+✅、状況変化は `> **YYYY-MM-DD 更新:**` を積層。計画は消さない)。

**時系列の生記録は `docs/harness/log.md`(追記専用アーカイブ)。** 作業の区切りごとに
末尾へ追記する。通常は全文ロードしない — 経緯を掘るときだけ読む。

主旨は **harness(`plugins/harness/`)の改善** — セッション引き継ぎハーネスを各リポジトリへ
配布するプラグイン。配布物(`skills/init/assets/`)を変更したら:

- **バージョン刻印を上げる**(そのファイルの内容が変わった版を書く)。
  刻印はファイルごとに異なるのが正常 — 揃えると配布先の世代差分を検出できなくなる。
- **配布済みリポジトリへの反映は `/harness:init` の再実行**(冪等なので既存の正典は壊れない)。
  どこが古いかは `grep -r "harness-template v"` で分かる。
- `scripts/install.sh` は破壊的、`scripts/survey.sh` は読み取り専用。
  **survey.sh だけが SKILL.md の `!` 記法で自動実行される** — この境界を崩さないこと
  (`!` はスキルを読んだだけで無条件に走るため、破壊的スクリプトを置くと事故になる)。
