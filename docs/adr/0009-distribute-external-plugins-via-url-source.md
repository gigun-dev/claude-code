# 外部リポジトリのプラグインはURL参照で配布する

Date: 2026-10-29
Implementation: done

上流リポジトリが管理されている外部プラグインを自リポジトリへ複製すると、上流の更新追従や差分管理の負担が常時発生する。Claude Code と Codex のマーケットプレイスはいずれも外部 Git URL による参照と各ホストでの自動更新に対応している。

独自実装のプラグインや単体スニペットを除き、上流がプラグイン定義を持つサードパーティ製スキルは plugins ディレクトリへ実体を置かず、marketplace.json の url または git-subdir ソースとして登録する。更新は各ホストのプラグイン更新機能に委ねる。

Accepting: オフライン時に初回のプラグイン取得ができず上流の可用性に依存する
Rejected: 上流コードを plugins に vendor 複製する — 追従の手間と自リポジトリの肥大化を避けるため
