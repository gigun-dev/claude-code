# todo と adr を 1 つの配布単位に統合する

Date: 2026-09-10
Implementation: done

todo と adr は「エージェントが読む、持続的な文脈」という同じ方針の両輪で、分かれていたせいで ADR ディレクトリの解決を todo 側へ重複実装する迂回が要った。1 つの配布単位にし、名前は呼び出し面の移行が最小で済む `todo` に据える(スキルは todo/adr/doctor の 3 つのまま)。0004 で pre-push を独立させたのとは逆だが、pre-push は実行主体が Git で独立しているのに対し、todo と adr はどちらも「エージェントがリポジトリのファイルを読む」で実行主体が同じだから。
