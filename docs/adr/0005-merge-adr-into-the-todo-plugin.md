# todo と adr を 1 つの配布単位に統合する

Date: 2026-09-10

todo と adr は「エージェントが読む、リポジトリの持続的な文脈」という 1 つの方針の両輪で、利用者の全体 CLAUDE.md も 1 文で束ねている。分かれていたせいで 0003（他プラグインの場所を前提にしない）が噛み、ADR ディレクトリの解決を todo 側へ重複実装する迂回が必要になっていた（利用者の裁定）。名前は `todo` に据える —— 呼び出し面が `todo:todo` / `todo:adr` / `todo:doctor` になり、marketplace・各リポジトリの CLAUDE.md・install パスの移行が最小で済む。スキルは 3 つのままにする。description が発火の主機構で、todo（作業の開始と状態変化）と adr（決まった領域に触れる前）は発火する瞬間が違うので、1 つにまとめると両方の発火率が落ちる。0004 で pre-push を独立させたのと逆の判断になるのは、pre-push は実行主体が Git で runtime が独立しているのに対し、todo と adr はどちらも「エージェントがリポジトリのファイルを読む」で、実行主体も読む瞬間も同じだから。0002（hook を持たない）は統合後もそのまま効く。
